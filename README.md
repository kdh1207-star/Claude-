# 디데이 포지 (D-Day Forge)

안드로이드 전용 디데이 위젯 앱. 앱에서 디데이를 여러 개 만들고, 홈 화면에 위젯을 추가할 때
열리는 화면에서 디데이 하나와 테마를 골라 띄운다.

## 기능
- 디데이 여러 개 생성/수정/삭제 (디데이 모드: D-3 / D-DAY / D+2, 기념일 모드: 시작일=1일)
- 위젯 추가 시 설정 화면 → 디데이 선택 → 테마 선택 + 세부 커스터마이즈
- 위젯을 탭하면 언제든 다시 꾸미기
- 자정마다 자동 갱신
- 디자인을 "내 테마"로 저장해 다른 위젯에서 재사용

## 디자인 구조 (요소 분리)
모든 테마는 `style/StyleElements.kt`의 독립된 부품들을 조합한 것일 뿐이다.
테마 전용 그리기 코드가 없어서, 어떤 테마의 텍스처/장식/글꼴이든 다른 테마와 섞어 쓸 수 있다.
편집기의 각 섹션에 있는 "가져오기"는 다른 테마에서 그 섹션의 요소만 복사한다.

| 부품 | 선택지 |
|---|---|
| 형태 | 사각형, 둥근 사각형, 알약, 원, 모서리 깎기, 비대칭 컷, 티켓, 픽셀 계단 (+ 모서리 크기, 여백) |
| 배경 | 단색, 선형/원형 그라데이션 (+ 두 색, 각도, 불투명도) |
| 텍스처 | 주사선, 인터레이스 노이즈, CRT, 격자, 신스웨이브 지평선, 도트, 하프톤, 노이즈, 사선, 카본, 회로, 종이, 별, 글리치, 육각형, LCD 픽셀 (+ 색, 진하기, 크기) |
| 테두리 | 실선, 이중선, 파선, 점선, 네온 글로우, 오프셋 그림자 (+ 색, 두께) |
| 장식 | 코너 브래킷, 터미널 타이틀바, HUD 눈금, 마스킹 테이프, 픽셀 코너, 사이드 스트라이프, 경고 줄무늬 |
| 글꼴 | 숫자/제목 각각 21종 (Orbitron, VT323, Ubuntu Mono, Press Start 2P, 검은고딕, 도현체, 나눔고딕코딩, 개구체 등) |
| 글자 | 숫자/제목/날짜 색, 크기, 자간, 대문자, "숫자만 크게" |
| 효과 | 그림자, 글로우, 외곽선, 색수차, 입체 그림자 (+ 색, 강도) |
| 배치 | 클래식, 숫자만 크게, 터미널, 좌우 분할, 라벨 강조 / 정렬 / 표시 형식 / 프롬프트 문구 |

기본 테마: 하나씩 새로 만드는 중 (`style/ThemePresets.kt`)

## 렌더링 방식
홈 화면 위젯(RemoteViews)은 커스텀 폰트·텍스처·글로우를 직접 지원하지 않기 때문에,
`render/WidgetRenderer.kt`가 위젯 전체를 위젯 크기에 맞는 비트맵 한 장으로 그린다.
앱의 미리보기도 같은 렌더러를 써서 미리보기와 실제 위젯이 똑같이 나온다.

## 빌드
- Android Studio로 열어서 실행하거나 `./gradlew assembleRelease`
- GitHub에 푸시하면 Actions가 APK를 빌드한다 (Actions → 최신 실행 → Artifacts `dday-forge-apk`)
- 최소 안드로이드 8.0 (API 26)
